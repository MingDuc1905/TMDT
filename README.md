## 🚀 Quick Start

### 1️⃣ Clone & Restore

```bash
git clone https://github.com/MingDuc1905/TMDT.git
cd TMDT-master/ShipFoodCore
dotnet restore
```

### 2️⃣ Config Database

```bash
# Tạo database MySQL
mysql -u root -p -e "CREATE DATABASE dbFoody CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# Import seed data (categories, users, menu items)
mysql -u root -p dbFoody < ../seed_mysql.sql
```

Sửa file `appsettings.json` hoặc set environment variables:

```bash
# Windows CMD
setx MYSQLHOST "localhost"
setx MYSQLPORT "3306"
setx MYSQLUSER "root"
setx MYSQLPASSWORD "your_password"
setx MYSQLDATABASE "dbFoody"

# Hoặc set connection string trực tiếp trong appsettings.json
```

<details>
<summary><b>📄 Cấu hình appsettings.json (click để mở)</b></summary>

```json
{
  "ConnectionStrings": {
    "dbFoodyEntities": "Server=localhost;Port=3306;Database=dbFoody;User=root;Password=your_password;"
  },
  "Authentication": {
    "Google": {
      "ClientId": "your_google_client_id",
      "ClientSecret": "your_google_client_secret"
    }
  },
  "Gemini": {
    "ApiKey": "your_gemini_api_key"
  }
}
```
</details>

### 3️⃣ Run

```bash
dotnet run
```

<p align="center">
  <b>🌐</b> <code>http://localhost:5000</code>
  &nbsp;&nbsp;·&nbsp;&nbsp;
  <b>💚</b> <code>http://localhost:5000/health</code>

  <b>🐳 Docker</b> (chạy từ thư mục gốc):<br>
  <code>cd .. && docker build -t fastship . && docker run -p 8080:8080 fastship</code>
</p>

## 🧠 Recommendation System

| Thuật toán | Cách hoạt động | Use case |
|------------|----------------|----------|
| **Collaborative Filtering** | Tìm user cùng sở thích → gợi ý món chưa đặt | Cá nhân hóa theo lịch sử |
| **Market Basket Analysis** | Món xuất hiện cùng đơn → GroupBy count desc | "Frequently Bought Together" |
| **Time-based** | Keyword matching: sáng (phở/bún), trưa (cơm), tối (lẩu/nướng), khuya (trà sữa) | Gợi ý theo khung giờ |
| **Trending** | Top bán chạy 48h (fallback: all-time) | Xu hướng hiện tại |

## 📡 API & SignalR Hub

<details>
<summary><b>🔌 JSON API Endpoints (click để mở)</b></summary>

| Method | Route | Mô tả |
|--------|-------|-------|
| `GET` | `/Home/GetReviews` | Load reviews (paginated) |
| `POST` | `/Home/SubmitReview` | Submit review |
| `GET` | `/Cart/ApiTangSoLuong` | Tăng số lượng (JSON) |
| `GET` | `/Cart/ApiGiamSoLuong` | Giảm số lượng (JSON) |
| `POST` | `/Cart/CheckCoupon` | Validate coupon |
| `POST` | `/Payment/ProcessPayment` | Mock payment |
| `POST` | `/Chatbot/SendMessage` | AI chatbot |
| `GET` | `/Admin/GetDashboardStats` | Dashboard stats |
| `GET` | `/Admin/GetRevenueChart` | Revenue chart data |
| `GET` | `/health` | Healthcheck |

</details>

<details>
<summary><b>🔌 SignalR Hub — <code>/nhantin</code> (click để mở)</b></summary>

| Method | Event | Mô tả |
|--------|-------|-------|
| `JoinOrderGroup(orderId)` | — | Join per-order group |
| `UpdateLocation(orderId, lat, lng)` | `shipperLocationUpdate` | 📍 Live coordinates |
| `SendToOrderGroup(msg, orderId, senderName, role)` | — | Group chat |
| `IsUserOnline(userId)` | `userOnline` / `userOffline` | Connection tracking |
| `NotifyNewMessage(userId, count)` | `unreadCountUpdate` | 🆕 Real-time badge |

</details>
